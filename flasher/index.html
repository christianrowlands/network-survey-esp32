Plug in your board

Connect the board to this computer with a USB cable that carries data. Cables that came with a charger often only carry power.

Your browser then lists the boards it can see. Pick the one named like USB JTAG/serial debug unit, CP2102N USB to UART Bridge Controller or USB Single Serial, and press Connect.

The board is not in the list
  • Try another cable. A charge-only cable is the most common cause.
  • On a DevKit with two USB ports, try the other port.
  • On Windows, a board with a CP210x or CH34x chip may need its driver from Silicon Labs or WCH.
  • On Linux, add yourself to the dialout group, then log in again.

    Supported boards
    
      
    An NS Scout is one of these ESP32 boards running the Scout software. Only the ESP32-C5
        also hears 5 GHz Wi-Fi, which many access points use.
    
      
      
    
      

    
      
      
      Help
      
      
      
        Connecting to the board fails
        
        
          
      • Close anything else using the board: a serial monitor, the Arduino IDE, or this page
            in another tab.
        • 
          
      • Put the board in download mode, then press Connect board again. On a DevKit, hold
            BOOT, press and release RESET (RST on the C3 board), then release
            BOOT. On the XIAO, unplug it and hold B while you plug it back in.
        • 
          
      • Plug the board straight into the computer instead of through a hub.
        • 
        
      
      
      
      
      
        The install stopped partway
        
      The board is not damaged. Plug it back in and run the install again. If it keeps
          stopping at the same place, try another cable or USB port.
      
      
      
      
      
        The Scout does not start after the install
        
      Press RESET once (RST on the C3 board, R on the XIAO). A board that was put in download mode by
          hand sometimes waits for this before it starts the new software.
      
      
      
      
      
        I can't use Chrome or Edge
        
      The installer needs Web Serial, which only Chrome and Edge on a computer have. You can
          also flash the full image from the
          GitHub
          releases with esptool, as the release notes describe.

      About the Scout software
      
      
        
        
      • It only listens. The Scout hears Wi-Fi and Bluetooth and reports what it hears
          to the app. It never sends Wi-Fi frames, never joins a network, and never sends active
          scans or deauthentication frames.
        • 
        
      • Survey only where you are allowed to. Rules on capturing wireless traffic differ
          by country and by site. You are responsible for following them.
        • 
        
      • Open source. The firmware is on
          GitHub under the
          Apache License 2.0, with
          release
          notes for every version.
