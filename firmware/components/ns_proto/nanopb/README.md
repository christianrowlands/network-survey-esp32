# nanopb runtime

Unmodified copy of the nanopb 0.4.9.1 runtime (`pb.h`, `pb_common.*`,
`pb_encode.*`, `pb_decode.*`) from https://github.com/nanopb/nanopb at tag
`0.4.9.1`. Licensed under the zlib license in `LICENSE.txt`.

The generator version in `scripts/requirements-proto.txt` must match this
runtime. To upgrade, replace these files from the new tag, bump the pin, and
run `scripts/gen-proto.sh`.
